# Tags

Tags make entries discoverable. They're how someone browsing Phiacta by topic finds your entry without knowing its title.

## Basics

Tags are open-ended strings — use any values that fit. An entry can have multiple tags.

## Tips

- **Lowercase, hyphenated phrases are the conventional format** — e.g., `machine-learning`, `formal-verification`. This helps keep tags consistent across entries, but any format works.
- **Consider tagging the domain as well as the specifics.** For example, an entry about a specific optimization algorithm could include both the algorithm name and the broader field (`optimization`, `convex-optimization`) to improve discoverability.
- **Include methodology tags when relevant.** `lean-verified`, `benchmark`, `simulation`, `proof-of-concept`.
- **A few well-chosen tags go a long way.** 3–7 tags is a reasonable range for most entries. More is fine if each tag genuinely helps someone find the entry.
- **Check for existing tags first.** Searching for entries in the same area and reusing their tags helps maintain consistency. That said, if no existing tag captures what you need, create a new one.
